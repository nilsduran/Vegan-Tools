# Funding options

*Checked 2026-11-15. Re-check status before applying.*

- **[NLnet](https://nlnet.nl/funding.html)** (€5k–50k EU grants): not planning to apply. Next deadline 3 Jan 2027, 12:00 CET. NGI Zero Commons closed in June 2026; the successor fund, Restack, excludes generative-AI projects under 1M users. Since 20 Oct 2026, [NLnet's AI policy](https://nlnet.nl/foundation/policies/generativeAI/2.0/) bans AI-written proposals and AI-produced code or docs in funded work. Only non-AI parts (taxonomy, classifier, OSM data) would qualify.
- **[EA Animal Welfare Fund](https://funds.effectivealtruism.org/funds/animal-welfare)**: grant, always open, individuals can apply. Medium fit: animal-ethics funder with no AI ban, but its priorities are farmed and wild animals, so it needs a measurable animal-impact case.
- **[Liberapay](https://liberapay.com/about/)**: recurring donations, open. High fit on values (non-profit, no cut, no tracking). Small income until there's an audience. Under an hour to set up.
- **[GitHub Sponsors](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/about-github-sponsors-for-open-source-contributors)**: donations, no fees on sponsorships from personal accounts. Medium-high fit, since the repo is already on GitHub. Check that Spain is a supported region at sign-up.
- **[Open Source Collective](https://docs.oscollective.org/getting-started/acceptance-criteria)**: fiscal host with a public ledger, open. Medium fit. Requires moving the repo to a GitHub organisation; a host fee applies.
- **[FLOSS/fund](https://floss.fund/faq/)**: grants of $10k–100k, reviewed quarterly via a `funding.json` manifest. Low fit for now: it skips very new or little-used projects (Vegan Tools started July 2026).
- **Not open now:** [ACE Movement Grants](https://animalcharityevaluators.org/movement-grants/) (round 12 closed 18 Oct 2026; watch for 2027); Generalitat Catalan-language grants (no 2026 call for apps found).

**Suggested next step:** Liberapay and GitHub Sponsors profiles, linked from `/about`.
